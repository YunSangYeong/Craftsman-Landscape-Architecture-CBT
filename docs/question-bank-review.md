2026-10-27, 기본 JSON에 실제 등록한 문항을 기준으로 한다. 사용자 로컬 등록은 집계하지 않는다.

전부 AI 일반 지식으로 작성한 자체 제작 자료다. 원문 기출0·복원0, 출제 연도·회차 모두 null. 작성 위치 외에 직접 읽지 않은 외부 자료를 근거로 붙이지 않았다. CC BY 4.0은 자체 작성 원고의 제공 조건이며 외부 자료 재배포 허가를 의미하지 않는다.

## 원고와 보존

- LA-0001~LA-0090: 기존 문항의 모든 필드와 순서를 그대로 보존했다. 정규 JSON SHA256 회귀 검사로 확인한다.
- LA-0091~LA-0190: 신규 개념형100개. `scripts/expanded-concepts.txt`에 질문·오답3개·정답·해설을 직접 작성했다.
- LA-0191~LA-1000: 신규 계산 문항군27개 × 조건30개. `scripts/expanded-calculations.py`에 입력·공식·단위·해설을 명시했다.
- `python scripts/author-bank.py`로 같은 ID·순서·결과를 재생성한다. 난수 없이 입력을 결정하며 Fraction으로 신규 계산값을 만든다. 원액량은 세척액 부피 계산이며 농약 살포 지침이 아니다. 시공 수치·식재 밀도·파종률 등은 계산용 가정이다.

## 내부 검토 범위

개념형은 각 질문과 정답을 해설에 대조하고 오답이 동일 조건에서 정답이 되는지 확인했다. 낙엽·상록과 침엽·활엽 분류, 토양 입경과 구조, 물질 이동 조직, 기능도와 실제 시공도, 재료와 작업 품질을 구분했다. 단정하기 어려운 효과는 조건을 함께 명시했다. 규정 치수나 제품별 처방 수치는 출제하지 않았다.

신규 개념형의 주제별 질문을 기존60개와 비교했다. 예를 들어 기존 '수목 선정을 위한 일조'와 신규 '기공·증산의 생리', 기존 '배수구 청소'와 신규 '관수관 누수 진단'처럼 다른 학습 목표인지 검토했다. 상록과 낙엽, 소나무와 잣나무 등 비교 가능한 짝은 학습 대상이 달라 유지했다. 의미상 유사한 주제를 완전히 배제했다는 보장은 하지 않는다.

자동 검사는 ID와 NFKC·공백 정규화 본문 및 보기 재배치 중복, 필수 필드와 서로 다른 보기4개, 정답 번호, 자체 제작의 연도·회차 null, 상태, 이용 조건을 확인한다. 계산형840개는 생성 Python과 별도의 TypeScript 수식으로 결과·정답 보기·단위·동치 보기·문항군별 입력 중복을 검사한다. 신규 조건은 정답과 오답을 소수 둘째 자리까지 정확히 나타낼 수 있도록 구성해 반올림이 정답을 바꾸지 않는다. 기존90개는 이 확장을 이유로 수정하지 않았다.

이는 AI 작성자의 내부 문장·개념 검토와 자동 수치 검사다. **외부 전문가 검수, 공인 정답 검증, 최신 공식 출제기준 대조는 미완료**다. 공식 자료 접근이 차단된 상태를 검증 완료로 바꾸지 않았다. 내부 검토 통과만 `reviewed`로 등록하며 검증 대기 자료는 학습에 넣지 않는다.
