# 조경기능사 필기 CBT

전기기능사 CBT의 화면과 기능을 재사용한 비공식 조경 학습 앱입니다. 기본 문제은행은 **내부 검토 완료 1,000문항**입니다. 공식 시험 규칙 검증과 외부 전문가 검수는 미완료입니다.

## 구현

실전 모의시험·랜덤 학습, 답안 선택 후 Space 이동, 문제 번호 이동, 절대 종료 시각과 자동 제출, 새로고침 복원, 결과·해설·오답 복습, 북마크·통계, JSON/CSV 가져오기·중복 제거·로컬 검수 승인·내보내기를 제공합니다. 학습 기준 선택 메뉴와 상단 상시 면책 배너는 없습니다. 모바일 메뉴는 독립적으로 스크롤됩니다.

학습 기록은 `landscape-cbt:v1` localStorage에 저장합니다. 최근 응답 5,000개와 시험 30회를 보관합니다. 백업 내보내기는 제공하지만 백업 복원 UI는 없습니다. 저장 실패와 손상은 경고하며 손상 원본은 자동 덮어쓰지 않습니다. 초기화는 확인을 거치고 기본 문제은행은 유지합니다. iframe·시크릿 모드·브라우저별 저장 접근은 달라질 수 있습니다.

## 시험 규칙 — 공식 확인 미완료

공식 확인 대상은 Q-Net(https://www.q-net.or.kr/)입니다. 2026-10-27 공식 상세 페이지 접속 시 `curl: (56) CONNECT tunnel failed, response 403`이 발생했습니다. 공식 시험 과목, 출제 수·시간·배점·합격·과락, 적용 출제기준 판을 직접 확인하지 못했습니다.

현재 `src/qualification.ts`는 **학습용 가정**입니다: 조경일반 / 조경재료 / 조경시공 및 관리 각 20개, 총 60개, 60분, 4지선다, 정답률 60% 이상 합격, 과락 없음, 미응답 오답 처리. 이 명칭과 균등 분포가 최신 공식 시험 규칙이라는 주장은 하지 않습니다. 모든 문항은 같은 배점으로 계산하고 표시 점수와 합격 원값은 분리합니다. 공식 규칙 확인 후 설정과 검증을 갱신해야 합니다.

## 문제은행 — 실제 1,000개, 부족 0개

| 학습 영역 | 개념형 | 숫자 조건형 | 합계 |
| --- | ---: | ---: | ---: |
| 조경일반 | 54 | 280 | 334 |
| 조경재료 | 53 | 280 | 333 |
| 조경시공 및 관리 | 53 | 280 | 333 |
| 합계 | 160 | 840 | 1,000 |

원문 기출 **0**, 복원 **0**, 자체 제작 **1,000**. 중복 제거 후 기본 JSON의 내부 검토 완료 수이며 외부 전문가 검수 완료를 의미하지 않습니다. 대기·제외 문항 및 개인 등록분은 기본 수에 포함하지 않습니다.

기존 90개를 그대로 보존하고 개념형 100개와 계산 조건형 810개를 추가했습니다. 총 **개념형 160개 + 계산 조건형 840개**입니다. 계산형은 기존 3문항군 × 10조건 + 신규 27문항군 × 30조건입니다. 총 30문항군은 문제 맥락별 분류이며 일부는 같은 곱셈·비율 공식을 공유합니다. **1,000개의 독립 개념이나 기출 1,000개라는 의미가 아닙니다.** 숫자 조건형 비중은 84%입니다. 문항군별 목록과 검토 범위는 [문제은행 검토](docs/question-bank-review.md)에 기록했습니다.

AI 일반 지식으로 작성했으며 읽지 않은 교재나 공식 자료를 인용하지 않았습니다. 연도·회차는 모두 null입니다. 저장소 URL은 작성 위치이지 정답의 외부 증빙이 아닙니다. 원고는 `scripts/author-bank.py`, `scripts/expanded-concepts.txt`, `scripts/expanded-calculations.py`, 실제 학습 데이터는 `src/data/questions.json`입니다. 자체 제작 자료는 CC BY 4.0(https://creativecommons.org/licenses/by/4.0/)으로 제공합니다. 민간 기출은행은 복제하지 않았고 원문 재배포 권한도 확인하지 못했습니다.

개념 문장·보기·답안의 내부 검토와 자동 수치 검증을 수행하되 전문가 검수·공식 출제기준 대조와 구분합니다. 규정 수치 문제는 포함하지 않았습니다. 의미상 중복은 개념별 질문과 정답을 비교해 검토했으나 유사 주제의 중복 가능성을 완전히 배제할 수 없습니다. 숫자 family는 시험에서 우선 한 번씩 뽑고, 영역별 20개를 채울 독립 그룹이 부족할 때만 남은 고유 ID로 보충합니다. 현 은행은 영역별 개념형 53개 이상과 계산 family 10개이므로 한 시험에서 같은 숫자 문항군을 반복 추출할 필요가 없습니다.

## 로컬 실행

Node 24.19.0, React·TypeScript·Vite. 저장소 디렉터리에서:

```sh
npm ci --cache /tmp/landscape-npm-cache
npm run dev
npm test
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
python scripts/author-bank.py
```

시스템 Chromium이 없으면 `npx playwright install chromium` 후 환경변수 없이 브라우저 검사를 실행합니다. 생성은 결정적이며 기존 ID를 바꾸지 않습니다. 테스트·빌드의 실제 결과와 검수 한계는 [검증 기록](docs/validation.md)을 확인하세요.
